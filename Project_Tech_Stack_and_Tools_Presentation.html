Tool / Framework Type Role & Purpose in Project

Python 3.10+ Core Engine Backbone language powering business logic, data calculations, and background redistribution routines.

Technology Driver / Engine Role & Purpose in Project
MongoDB Atlas Cloud NoSQL Scalable document database storing dynamic schema collections for Users, Inventory, Donations, and Claims.
Motor & PyMongo Async Python Asynchronous, non-blocking MongoDB driver for concurrent read/write transactions and pool management.
Compound Indexes Query Engine Optimized indexes on status, tenant_id, email, and timestamps for sub-millisecond lookups.

Module / Algorithm Type Functionality & Business Impact
